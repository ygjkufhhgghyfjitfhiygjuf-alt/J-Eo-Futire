# J-Eo Future — Shop • Recharge • Earn

## 🚀 Features

### 👤 User Features
- 🔐 Email/Password এবং Google দিয়ে Login/Signup
- 🛍️ Product Shop (Cash on Delivery)
- 📱 MB & Minute Offer কিনতে পারবে
- 💰 Add Balance ও Withdraw সিস্টেম
- 📊 Complete Transaction History
- 🔔 Real-time Push Notifications
- 🌙 Dark Mode সাপোর্ট
- 📞 Live Support

### 🔧 Admin Features
- 📊 Real-time Dashboard (Orders, Users, Revenue)
- 📦 Product Management (Add/Edit/Delete)
- 📱 MB & Minute Offer Management
- 🛍️ Order Processing & Status Update
- 💰 Balance/Withdraw Request Approve/Reject
- 👥 User Management (Block/Unblock)
- 📢 Push Notification Broadcast
- 🖼️ Banner Management
- ⚙️ Payment Gateway Settings
- 📝 Activity Log

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6 Modules)
- **Backend:** Firebase
  - Authentication (Email/Password + Google)
  - Cloud Firestore (Database)
  - Cloud Messaging (Push Notifications)
  - Cloud Functions (Auto Push)
- **Hosting:** GitHub Pages / Vercel / Netlify / Firebase Hosting
